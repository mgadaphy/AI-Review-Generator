# AI Review Generator for WooCommerce

**A MOGADONKO AGENCY Project by Mo Gadaphy**

Automatically generate realistic product reviews using AI models for your WooCommerce store. This plugin helps to build social proof and increase customer trust by populating your products with authentic-sounding reviews.

## Features

*   **Automatic Review Generation**: Schedule daily tasks to generate new product reviews automatically.
*   **Multiple AI Providers**: Supports major AI models including OpenAI, Claude, and any provider available through OpenRouter.
*   **Customizable Review Style**: Tailor the tone and style of reviews to match your brand's voice (e.g., detailed, concise, enthusiastic, neutral).
*   **Smart Product Selection**: Define criteria for product selection, such as stock status, number of existing reviews, and publication date.
*   **WooCommerce Integration**: Seamlessly integrates with WooCommerce, adding reviews directly to your products.
*   **Admin Interface**: A dedicated dashboard to monitor review generation, view history, and configure settings.

## Requirements

*   WordPress 5.0 or higher
*   PHP 7.4 or higher
*   WooCommerce 4.0 or higher

## Installation

1.  Download the latest release from the [GitHub repository](https://github.com/mgadaphy/AI-Review-Generator).
2.  In your WordPress admin panel, go to **Plugins > Add New** and click **Upload Plugin**.
3.  Choose the downloaded ZIP file and click **Install Now**.
4.  Activate the plugin through the 'Plugins' menu in WordPress.

## Usage

1.  After activation, navigate to **AI Reviews > Settings** in your WordPress dashboard.
2.  Enter your API key for the chosen AI provider (e.g., OpenAI).
3.  Configure the review generation settings according to your needs.
4.  Reviews will be generated automatically based on your defined schedule.

## Known Issues

*   **Plugin Activation Failure**: The plugin is currently under active development to resolve a critical issue causing the website to crash upon activation. This is due to a class loading conflict within the WordPress environment. We are working on a fix.
